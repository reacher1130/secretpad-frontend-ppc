# BFIA组件预览功能

## 功能概述

在BFIA协议下的"已集成算法"菜单栏中，新增了一个"预览"按钮，点击后可以打开一个类似SecretFlow项目空间的画布页面，支持对BFIA组件进行拖拽操作。

## 功能特性

### 1. 预览按钮
- 位置：已集成算法页面右上角
- 图标：眼睛图标
- 功能：打开预览画布

### 2. 预览画布
- **左侧组件库**：
  - 显示所有可用的BFIA组件
  - 支持搜索过滤
  - 组件卡片显示：名称、域、版本、描述
  - 支持拖拽到画布

- **右侧画布区域**：
  - 基于@antv/x6的图形画布
  - 支持组件拖拽放置
  - 支持画布缩放、平移
  - 支持节点连接（拖拽端口连线）
  - 支持节点选择、删除
  - 网格背景和现代化UI
  - 键盘快捷键支持

### 3. 工具栏功能
- **适应画布**：自动调整视图以显示所有内容
- **全选**：选择画布上的所有组件
- **取消选择**：取消所有选中的组件
- **删除选中**：删除当前选中的组件（仅在有选中时显示）
- **清空画布**：清除所有已放置的组件
- **关闭**：关闭预览画布

## 技术实现

### 组件结构
```
bfia-component-list/
├── bfia-component-list.view.tsx      # 主页面组件
├── bfia-component-list.service.ts    # 数据服务
├── bfia-preview-canvas.tsx          # 预览画布组件
├── bfia-preview-canvas.less         # 画布样式
└── index.ts                         # 导出文件
```

### 数据流
1. 通过`/v1/interconn/components/listCompListVO` API获取BFIA组件列表
2. 组件数据传递给预览画布
3. 画布支持实时搜索和过滤
4. 拖拽操作创建画布节点

### 样式设计
- 复用了SecretFlow项目空间的设计风格
- 响应式布局，支持不同屏幕尺寸
- 现代化的卡片设计和交互效果
- 统一的色彩方案和字体

## 使用方法

1. 在BFIA协议下进入"已集成算法"页面
2. 点击右上角的"预览"按钮
3. 在左侧组件库中搜索或浏览组件
4. 拖拽组件到右侧画布中
5. 拖拽节点端口进行组件连接
6. 使用工具栏功能管理画布内容

## 交互操作

### 拖拽操作
- **拖拽组件**：从左侧组件库拖拽到画布
- **移动节点**：直接拖拽画布中的节点
- **连接组件**：拖拽节点端口到另一个节点端口

### 选择操作
- **单选**：点击节点进行选择
- **多选**：拖拽框选多个节点
- **全选**：点击"全选"按钮或按Ctrl+A
- **取消选择**：点击空白区域或按Escape键

### 删除操作
- **删除选中**：选中节点后按Delete键或点击"删除选中"按钮
- **清空画布**：点击"清空画布"按钮清除所有内容

### 查看操作
- **缩放**：使用鼠标滚轮或Ctrl+滚轮
- **平移**：拖拽空白区域
- **适应画布**：点击"适应画布"按钮
- **查看详情**：双击节点查看组件信息

## 注意事项

- 预览功能仅用于组件展示和布局设计
- 不支持保存画布状态
- 组件连接功能为演示性质
- 需要确保后端API `/v1/interconn/components/listCompListVO` 正常工作
